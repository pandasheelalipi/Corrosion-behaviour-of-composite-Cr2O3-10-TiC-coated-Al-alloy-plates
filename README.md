# Corrosion Behaviour of Composite (Cr₂O₃ + 10%TiC) Coated Al Alloy Plates

## Publication Details
- **Journal:** Materials Today: Proceedings — Elsevier (2023)  
- **DOI:** https://doi.org/10.1016/j.matpr.2023.06.296  
- **My Role:** Data Curation

## About this Research
This published study examines the corrosion resistance of 
HVOF-sprayed Cr₂O₃ + 10%TiC ceramic composite coatings on 
Al-6061 aluminium alloy, tested via salt spray, potentiodynamic 
polarisation, and electrochemical impedance spectroscopy.
